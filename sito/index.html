Come funziona

Tutto gira sul tuo server: codice, chat e dati restano lì. Ciccio non è esposto su internet, ci arrivi dalla tua rete privata Tailscale ed entri con una passkey.

Sicuro per costruzione, provato davvero

Ciccio fa eseguire comandi a degli agenti sul tuo server. Per questo la sicurezza non è un'opzione.

Un agente, un repo

I comandi girano in una sandbox (bubblewrap): l'agente scrive solo nel suo progetto e non vede gli altri, le credenziali di Claude, le chiavi SSH o la configurazione del server.

Internet solo dove serve

Un firewall in uscita lascia passare solo i domini consentiti (Anthropic, GitHub, npm…). Quelli nuovi li approvi tu, uno per uno.

Il permesso lo dai tu

Per ogni chat scegli quanto lasciar fare all'agente. Le azioni che contano diventano una card: Consenti o Rifiuta, anche dalla notifica.

Aggiornamenti firmati

Companion e app desktop installano solo release firmate (Ed25519) dalle GitHub Actions: un server compromesso non può farti installare altro.

Nessuna porta aperta

Ciccio si raggiunge dalla tua rete Tailscale, in https, e si entra solo con una passkey: Face ID, impronta o PIN.

Provato su server veri

CI a ogni modifica, installazione rifatta da zero su Ubuntu vuoto e rilanciata senza rifare niente, sandbox verificata con un agente al lavoro. E Ciccio gira ogni giorno in produzione.

Installazione in una ventina di minuti

Ti servono un server Ubuntu 24.04 (anche un VPS da pochi euro, 2 CPU e 4 GB di RAM), un abbonamento Claude a pagamento (Pro, Max, Team o Enterprise) e un account Tailscale gratuito.

# sul server, come root
apt-get install -y git
git clone https://github.com/danielecosta7/ciccio ciccio-setup
bash ciccio-setup/deploy/setup.sh

Una procedura guidata: per ogni passo ti dice cosa fa e chiede conferma. Se la interrompi, la rilanci e riparte da dove eri.

  1. Tailscale: apri il link che compare e il server entra nella tua rete privata.
  2. GitHub: inserisci su github.com il codice che ti mostra (puoi saltarlo).
  3. Claude: accedi con il tuo account e incolla il codice di conferma.
  4. Accesso: apri l'indirizzo di Ciccio, inserisci il codice di attivazione e crea la tua passkey.

Tutti i dettagli: guida completa all'installazione.

Domande frequenti

Le risposte brevi a quello che chiedono tutti.

Serve una chiave API di Anthropic?

No, e non va usata. Ciccio funziona con il login del tuo abbonamento claude.ai (Pro, Max, Team o Enterprise), come Claude Code sul tuo PC. Fa lavorare gli agenti in modalità agentica: chat lunghe che tengono il contesto da un giro all'altro, con i connettori e le skill del tuo account. Con una chiave API il contesto si perderebbe. Se sul server c'è una chiave API, Ciccio non la passa agli agenti.

Quanto costa?

Ciccio è gratis e open source (AGPL-3.0). Paghi il tuo abbonamento Claude, i cui limiti di utilizzo sono condivisi da tutti gli agenti, e il server.

Che differenza c'è con Claude Code?

Gli agenti sono Claude Code. Ciccio aggiunge quello che serve per farne lavorare tanti insieme: un server sempre acceso, un agente per progetto, la sandbox, i permessi dal telefono, le notifiche, il riepilogo del mattino e le routine.

I miei dati dove vanno?

Restano sul tuo server. Le richieste ai modelli vanno ad Anthropic con il tuo account, come con Claude Code. L'elenco completo delle connessioni esterne è nella documentazione sulla sicurezza.

Funziona senza server, sul mio PC?

No: Ciccio è pensato per un server Linux sempre acceso, così gli agenti lavorano anche quando il PC è spento.

Posso usarlo da fuori casa?

Sì, dal telefono o dal PC con Tailscale acceso, da qualunque rete. Se vuoi puoi aggiungere anche un tuo dominio.

È in inglese?

Per ora interfaccia e documentazione sono in italiano.
